# omicsuite: Portfolio-Grade Analytical Pipelines

High-level pipelines that wrap a fitted model together with the
diagnostic checks, plots, and verdicts you'd want before trusting it.
The first release covers Cox proportional hazards survival analysis; see
[`fit_coxph_pipeline()`](https://real-peekei.github.io/omicsuite/reference/fit_coxph_pipeline.md).
