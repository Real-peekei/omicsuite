# Summarize a `multiomics_pipeline` object

Summarize a `multiomics_pipeline` object

## Usage

``` r
# S3 method for class 'multiomics_pipeline'
summary(object, ...)
```

## Arguments

- object:

  A `multiomics_pipeline` object, as returned by
  [`integrate_multiomics()`](https://real-peekei.github.io/omicsuite/reference/integrate_multiomics.md).

- ...:

  Ignored.

## Value

A list with elements `variance_explained`, `stability`, and `verdicts`.
