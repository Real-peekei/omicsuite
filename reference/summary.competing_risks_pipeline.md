# Summarize a `competing_risks_pipeline` object

Summarize a `competing_risks_pipeline` object

## Usage

``` r
# S3 method for class 'competing_risks_pipeline'
summary(object, ...)
```

## Arguments

- object:

  A `competing_risks_pipeline` object, as returned by
  [`fit_competing_risks_pipeline()`](https://real-peekei.github.io/omicsuite/reference/fit_competing_risks_pipeline.md).

- ...:

  Ignored.

## Value

A list with elements `event_summary`, `cif_summary`, and `verdicts`.
